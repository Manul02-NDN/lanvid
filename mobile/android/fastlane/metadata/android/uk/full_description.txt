LanVid Monitor перетворює ваш Android-смартфон на персональний вушний монітор (IEM-мікшер) з ультранизькою затримкою для LanVid Studio на Windows та macOS.

Керуйте власним міксом до 64 студійних каналів із вашої DAW прямо зі сцени або репетиційної бази — усе мікшування та студійна DSP-обробка виконуються на ПК, а смартфон отримує готовий компактний стереопотік по локальному Wi-Fi.

ОСНОВНІ МОЖЛИВОСТІ:
• Нативний C++ AAudio рушій: ультранизька фіксована затримка 5–20 мс та надійна робота у фоні з вимкненим екраном.
• Студійний кодек Opus CELT 48 кГц та Lossless PCM: вибір 128 / 192 / 256 кбіт/с (повна смуга 20 Гц – 20 кГц) або Lossless 24-біт PCM на льоту.
• Персональний мікшер 64→2: живі VU-метри, назви каналів із ПК, плавні фейдери без клацань, панорама, Mute та Solo з автозбереженням.
• Серверний Monitor FX DSP: фільтр високих частот HPF (20–250 Гц), 3-смуговий EQ (±12 дБ), стереокомпресор з індикатором Gain Reduction, Master Volume та захисний Brickwall-лімітер (-0.5 dBFS) для безпеки слуху.
• Автопошук у мережі: миттєво знаходить LanVid Studio по Wi-Fi через mDNS (_lanvid._udp) або підключається за IP.
• Режим Demo Studio Preview: перевіряйте всі 8 каналів, VU-метри та Monitor FX DSP локально без підключеного ПК.
• 100% локальна мережа та приватність: жодних акаунтів, хмарних серверів, телеметрії чи реклами.
