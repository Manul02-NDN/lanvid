Вітаємо у LanVidSDK v2.4.0 для macOS та iOS

Універсальний SDK для передачі відео та звуку в локальній мережі з наднизькою затримкою (< 4–6 мс E2E) з апаратним прискоренням Apple Silicon NEON (M1–M4) та Intel AVX2.

Інсталятор автоматично налаштує:

  • Core C/C++17 & XCFramework: універсальну бібліотеку liblanvid_core.dylib (arm64 + x86_64), LanVidCore.xcframework (iOS, Simulator, macOS), заголовки у /usr/local/include/lanvid.
  • CMake & pkg-config: миттєве підключення через find_package(LanVidSDK REQUIRED) та інтеграцію з Homebrew.
  • Swift Package LanVidKit: ідіоматичний async/await API для CVPixelBuffer, Metal та AVAudioEngine.
  • Python SDK & діагностику: глобальний import lanvid_sdk, правила macOS Firewall та утиліту lanvid-sdk-info.
