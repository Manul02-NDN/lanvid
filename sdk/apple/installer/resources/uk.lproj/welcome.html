LanVid Video (v3.0.0) & CrossLink Audio (v1.0.0) SDK

Ви можете встановити обидва протоколи разом, лише відеопротокол LanVid або лише аудіопротокол CrossLink на кроці вибору компонентів:

  • LanVid Video SDK v3.0.0 (/usr/local/LanVidSDK): ультранизька затримка відео (AVX2/NEON DCT, HW H.264/H.265, XOR FEC, AIMD), 2-канальне стерео аудіо, Multi-Cam, ISO Recorder, Tally/Intercom.
  • CrossLink Audio SDK v1.0.0 (/usr/local/CrossLinkSDK): професійний 64-канальний студійний AoIP (48/96 kHz, MasterClock, FEC/NACK, 1+1 Wi-Fi redundancy), Full-Duplex DAW SHM Bus, MIDI 2.0, Personal Monitor Bus та Layer-2 Grid.

English: Choose to install both protocols together, LanVid Video SDK only (video + 2ch stereo audio), or CrossLink Audio SDK only (64ch AoIP + MIDI 2.0 + Monitor + Grid). Each component installs cleanly with zero cross-protocol dependencies.
