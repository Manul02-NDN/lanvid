LanVidSDK v2.4.0 успішно встановлено!

Запустіть швидку діагностику, перевірку SIMD (NEON/AVX2) та self-test у Терміналі:

lanvid-sdk-info

1. Xcode / Swift (iOS 15+ та macOS 12+)

Додайте локальний Swift Package /usr/local/LanVidSDK/apple у Xcode (File → Add Package Dependencies → Add Local...) або підключіть /usr/local/LanVidSDK/apple/LanVidCore.xcframework:

import LanVidKit
let rx = try LanVidReceiver()
try rx.start(config: .init(bindPort: 5000))

2. CMake (C++17 / C++20)

find_package(LanVidSDK REQUIRED)
target_link_libraries(my_app PRIVATE LanVidSDK::Core)

3. Python 3

python3 -c "import lanvid_sdk; print(lanvid_sdk.LanVidSDK().simd)"
