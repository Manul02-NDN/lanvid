Встановлення SDK успішно завершено!

Перевірте встановлені протоколи у Терміналі:

lanvid-sdk-info        # LanVid Video SDK (v3.0.0)
crosslink-sdk-info     # CrossLink Audio SDK (v1.0.0)

CMake (можна підключати окремо або обидва разом)

find_package(LanVidSDK REQUIRED)
target_link_libraries(my_video_app PRIVATE LanVidSDK::Video)

find_package(CrossLinkSDK REQUIRED)
target_link_libraries(my_audio_app PRIVATE CrossLinkSDK::Audio)

Python 3

python3 -c "import lanvid_sdk; print(lanvid_sdk.LanVidSDK().version)"
python3 -c "import crosslink_sdk; print(crosslink_sdk.CrossLinkSDK().version)"
