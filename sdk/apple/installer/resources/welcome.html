LanVidSDK v2.4.0 для macOS та iOS

Універсальний SDK для передачі відео та звуку по локальній мережі з наднизькою затримкою (< 4–6 мс E2E) на базі Apple Silicon NEON (M1–M4) та Intel AVX2.

Що буде встановлено та налаштовано автоматично:

  • Core C/C++17 & XCFramework: універсальна бібліотека liblanvid_core.dylib (arm64 + x86_64), LanVidCore.xcframework (iOS, Simulator, macOS), заголовки /usr/local/include/lanvid.
  • CMake & pkg-config: миттєве підключення через find_package(LanVidSDK REQUIRED).
  • Swift Package LanVidKit: ідіоматичний async/await API для CVPixelBuffer, Metal та AVAudioEngine.
  • Python SDK & діагностика: import lanvid_sdk з будь-якої папки, виняток у macOS Firewall та команда lanvid-sdk-info.

English: This installer deploys the universal LanVidSDK v2.4.0 (arm64 NEON + x86_64 AVX2) into /usr/local/LanVidSDK, configures Xcode/SwiftPM/CMake/pkg-config/Python bindings, checks Xcode Command Line Tools and UDP port availability, and sets up macOS Application Firewall permissions.
