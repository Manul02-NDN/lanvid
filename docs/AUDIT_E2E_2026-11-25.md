## Знахідки середовища (не код LanVid)

* **USB-адаптер Mac `en11` (Realtek RTL8153, драйвер Apple CDC-ECM `AppleUserECM`) відкидає кадри залежно від вмісту**:
  Windows → Mac по дроту губилось 35–70 % пакетів LanVid; ті самі байти, відтворені з Python, губляться так само;
  звичайний UDP/DSCP проходить. Windows → Wi-Fi Mac — 0 втрат. Рекомендація: інший адаптер або драйвер Realtek (NCM/вендорний).
* Windows-бінарники й встановлена Studio **застарілі** (15:33, до `ec46b64`/`c2c58f1`): старий `sender.exe` давав ~16 провалів/с.
* L2 Mac↔Windows: доступ до `/dev/bpf*` користувач відкрив сам (`chgrp admin` + `g+rw`, діє до перезавантаження); прогін — у таблиці вище.
